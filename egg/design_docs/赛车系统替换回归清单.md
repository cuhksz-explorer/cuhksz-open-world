# 赛车系统替换回归清单

## 单机回归

- 打开含 `VehicleDealerNPC` 的场景后，靠近 NPC 时出现统一交互提示。
- 按 `F` 能正常打开选车界面，离开 NPC 或关闭界面后提示状态恢复正常。
- 选中任意 `VehicleData` 后，车辆会在 `CarSpawnPoint` 正常生成。
- 重复选车时，上一辆车会被替换，不会残留多辆旧车。
- 靠近新生成车辆时，出现统一的 `按 F 上车` 提示。
- 上车后：
  - 左下显示速度。
  - 右下显示驾驶按键说明。
  - 共享交互提示被正确清空。
- 驾驶过程中：
  - `W/S/A/D` 可用。
  - `Space` 刹车正常。
  - `Esc` 可下车。
- 下车后：
  - 玩家回到车辆侧边。
  - 驾驶 HUD 正常隐藏。
  - 车辆重新显示 `按 F 上车` 提示。

## 联机回归

- Host 场景中通过 NPC 选车后，客户端能看到同一辆新生成车辆。
- Client 通过 NPC 选车后，请求会发到 Host，Host 场景会生成车辆。
- 同一时间只有一名玩家能进入同一辆车。
- 驾驶者移动车辆时，其他玩家能看到车辆同步移动、转向、停车。
- 驾驶者按 `Esc` 下车后，其他玩家看到车辆占用被释放。
- 多次重复生成车辆时，旧车辆能在所有联机端一起销毁。

## 场景替换回归

- 执行 `Tools/赛车/系统二替换系统一/一键配置当前场景` 后：
  - 场景内存在 `VehicleDealerNPC`、`VehicleShopCanvas`、`Carcanvas`、`CarSpawnPoint`。
  - `InteractableNPC` 已绑定商店和生成点。
  - 旧 `VehicleController` 车辆被停用。
- 执行 `Tools/赛车/系统二替换系统一/批量配置 Assets/scene 全部场景` 后：
  - 每个校园场景都完成上述基础配置。
  - `Assets/Carsystem/CarPrefabs` 下车辆预制体都已补齐联机组件。

## 故障排查

- 若 NPC 靠近无提示，先检查场景里是否存在 `InteractPrompt_Shared`。
- 若能打开商店但无法生成车辆，检查 `InteractableNPC.availableVehicles` 和 `spawnPoint`。
- 若单机能生成但联机不同步，检查 Carsystem 车辆预制体上是否已有：
  - `NetworkIdentity`
  - `NetworkTransformReliable`
  - `CarSystemVehicleNetworkProxy`
