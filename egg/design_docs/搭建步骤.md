   # 寝室商城 - 纯 C# Unity UI 搭建步骤

## 一、导入脚本

将 `DormMall` 文件夹复制到 Unity 项目的 `Assets/` 下，例如：

```
Assets/
└── DormMall/
    ├── ProductDatabase.cs
    ├── ProductItemUI.cs
    ├── DormMallUI.cs
    └── Editor/
        ├── DormMallEditor.cs
        └── ProductDatabaseEditor.cs
```

## 二、创建商品数据库

1. 在 Project 窗口右键 → **Create** → **DormMall** → **Product Database**  
   或菜单 **Assets** → **DormMall** → **创建商品数据库**

2. 会生成 `Assets/Resources/DormMall/ProductDatabase.asset`

3. 将寝室商城的商品图片放入 `Assets/Resources/DormMall/`，并按分类建子文件夹，例如：
   ```
   Resources/DormMall/
   ├── 绿植摆件/
   │   ├── 多肉.png
   │   ├── 绿箩.png
   │   └── ...
   ├── 墙面装饰/
   ├── 照明氛围/
   └── 生活用品/
   ```

4. 图片导入后，在 Inspector 中勾选 **Texture Type** → **Sprite (2D and UI)**，以便作为 Sprite 使用。

5. 在 `ProductDatabase` 的 `products` 列表中，为每个商品设置 `iconPath`，格式为：`DormMall/分类/文件名（不含扩展名）`  
   例如：`DormMall/绿植摆件/多肉`

## 三、创建商城 UI

1. 菜单 **GameObject** → **DormMall** → **创建寝室商城 UI**

2. 场景中会生成 `DormMallCanvas`，包含：
   - 顶部栏（标题 + 金币）
   - 分类按钮栏
   - 商品网格（ScrollView）
   - 购买弹窗
   - 提示条（Toast）

3. 选中 `DormMallCanvas`，在 Inspector 中找到 `DormMallUI` 组件：
   - **Database**：拖入 `ProductDatabase.asset`（若放在 Resources/DormMall，可不填，会自动加载）
   - **Initial Coins**：初始金币
   - **Price Multiplier**：价格倍率（1=原价）

## 四、运行与测试

1. 点击 Play，商城界面会显示。

2. 点击分类切换商品列表，点击「购买」弹出详情，确认后扣除金币并触发事件。

3. 在代码中订阅购买事件：

```csharp
var mall = FindObjectOfType<DormMall.DormMallUI>();
if (mall != null)
{
    mall.OnPurchaseComplete += (id, name, category, price, coins) =>
    {
        Debug.Log($"购买: {name}, 花费 {price}, 剩余 {coins}");
        // 在此同步游戏内寝室装饰
    };
    mall.SetCoins(2000);  // 设置金币
    mall.AddCoins(100);   // 增加金币
}
```

## 五、自定义商品数据

在 `ProductDatabase` 的 Inspector 中可：
- 增删商品
- 修改名称、分类、描述、价格
- 为每个商品指定 `icon`（直接拖 Sprite）或 `iconPath`（Resources 路径）

## 六、常见问题

**Q: 商品不显示图标？**  
A: 检查 `iconPath` 是否与 Resources 下路径一致，且图片已设为 Sprite。

**Q: 分类或商品列表为空？**  
A: 确认 `ProductDatabase` 已正确赋值，且 `products` 列表中有数据。

**Q: 想用 TextMeshPro？**  
A: 修改 `ProductItemUI.cs`，将 `Text` 改为 `TextMeshProUGUI`，并添加 `using TMPro;`。
