# 《未名之海》可落地任务手册（详细版）

> 用途：直接填入任务系统、对话系统、关卡脚本  
> 体量：主线约 30h，支线约 70h  
> 单位说明：1 个“任务”可拆 3-8 个“分任务”  
> 统一模板：`任务ID / 时长 / 触发 / 参与NPC / 分任务 / 关键对白 / 分支 / 失败条件 / 奖励 / 后续影响`

---

## 0. 全局变量（建议）

- `GPA`：0.0 - 4.3
- `Stress`（压力）：0 - 100
- `Energy`（精力）：0 - 100
- `Money`（金币）
- `Rep_Academic`（学术声望）
- `Rep_Social`（社交声望）
- `Trust_Qinghe` / `Trust_Zhouyan` / `Trust_Gucheng`
- `Ethic`（价值倾向）：-100（功利）到 +100（理想）
- `Mystery_ZeroClass`（第零课调查进度）：0 - 100

当 `Stress >= 80` 时，自动附加 Debuff：  
- 考试型任务 QTE 时间缩短 20%  
- 对话失误率上升（错误选项阈值降低）

## 1. 主线任务链（30h）

## M0 序章：到港（2h）

### M0-1 报到日
- **时长**：20min
- **触发**：新游戏开始
- **NPC**：林渡（主角）、迎新学长、宿管阿姨
- **分任务**
  1. 前往报到点领取校园卡
  2. 完成宿舍入驻（输入角色基础背景）
  3. 绑定课表系统（引导 UI）
- **关键对白**
  - 迎新学长：“你以为大学是开始，其实它是放大镜。”
- **分支**
  - 礼貌/冷淡回应学长，影响 `Rep_Social` 初始值
- **失败条件**：无（教学关）
- **奖励**：`Money +200`，解锁地图
- **后续影响**：开启 M0-2

### M0-2 迷路与相遇
- **时长**：35min
- **触发**：完成 M0-1
- **NPC**：沈青禾、周砚、顾澄
- **分任务**
  1. 在教学楼迷路，询问 3 名路人
  2. 选择跟随其中一人带路（青禾/周砚/顾澄）
  3. 完成“第一顿饭”事件
- **关键对白**
  - 沈青禾：“路线可以算出来，人生不行。”
  - 周砚：“你先学会认识人，再谈认识世界。”
  - 顾澄：“如果都在赶路，谁来抬头看天？”
- **分支**
  - 选择跟随对象，决定首个关系线加成
- **失败条件**：在限定时间未到达，`Stress +5`
- **奖励**：目标 NPC 信任 +10
- **后续影响**：后续对话出现独有回忆选项

### M0-3 第零课传闻
- **时长**：25min
- **触发**：M0-2 完成后夜晚自动触发
- **NPC**：匿名论坛管理员“Null”
- **分任务**
  1. 浏览校园匿名论坛
  2. 收集 3 条“薯塔下第零课”帖子
  3. 决定是否关注“Null”账号
- **分支**
  - 关注：`Mystery_ZeroClass +10`
  - 忽略：后续需额外支线补进度
- **奖励**：神秘线入口

## M1 第一章：绩点风暴（5h）

### M1-1 选课战争
- **时长**：45min
- **触发**：开学周
- **NPC**：教务系统 AI、同班同学
- **分任务**
  1. 在 8 门课中选 5 门（每门有难度/兴趣/收益）
  2. 处理“课程冲突”问题
  3. 与室友讨论“刷分策略”
- **核心机制**：资源分配（时间点数）
- **分支**
  - 刷分优先：`GPA成长 +`，`Stress成长 ++`
  - 兴趣优先：`洞察`与剧情分支更多
- **失败条件**：未及时选课 -> 随机课表，`Ethic -5`
- **奖励**：课程技能树解锁

### M1-2 小组作业危机
- **时长**：60min
- **触发**：M1-1 完成后
- **NPC**：队友 A（摆烂）、队友 B（抄袭倾向）
- **分任务**
  1. 收集队友贡献度
  2. 决定是否默许抄袭
  3. 课堂答辩（QTE）
- **关键对白**
  - 队友B：“大家都这么做，只有你在乎流程。”
- **分支**
  - 默许抄袭：当下分数更高，后续触发学术风险线
  - 拒绝抄袭：短期扣分，`Rep_Academic +`
- **失败条件**：答辩失败 -> `GPA -0.1`、`Stress +10`
- **奖励**：`Money +300`（课程奖励）

### M1-3 期中崩溃夜
- **时长**：50min
- **触发**：`Stress >= 60` 或章节进度到期中
- **NPC**：心理中心值班同学、沈青禾
- **分任务**
  1. 在图书馆完成 3 轮复习小游戏
  2. 幻象战斗“均分幻影”前置
  3. 选择“硬抗”或“求助”
- **分支**
  - 求助：`Stress -20`，解锁心理支持系统
  - 硬抗：`Rep_Academic +5`，但后续风险升高

### M1-4 Boss：均分幻影
- **时长**：35min
- **机制**：三阶段心理战
  1. “比较”阶段：屏幕出现他人成绩干扰
  2. “否定”阶段：角色自语，需正确回应
  3. “重构”阶段：选择个人目标定义
- **胜利条件**：三次正确价值判断
- **奖励**：被动技能`稳定呼吸`（考试失败惩罚 -15%）

### M1-5 章末结算：第一份成绩单
- **时长**：30min
- **输出**：GPA/压力/关系动态
- **章节结论对白**
  - “你第一次意识到：成绩单会说话，但不会说真话。”

## M2 第二章：心动与错位（5h）

### M2-1 雨夜共伞事件
- **时长**：30min
- **触发**：与任一角色信任 >= 20
- **分任务**
  1. 送对方回宿舍
  2. 对话中回答 3 个价值问题
  3. 选择是否透露家庭背景
- **结果**：开启对应恋爱线/深友情线

### M2-2 深夜图书馆双人任务
- **时长**：60min
- **NPC**：恋爱候选角色
- **分任务**
  1. 协作完成论文资料检索
  2. 面对“前任来电/竞品邀约”干扰事件
  3. 做出“留人/放人”选择
- **关键机制**：关系边界判断
- **分支**
  - 过度控制：短期好感 +，长期信任 --
  - 尊重边界：短期平淡，长期信任 ++

### M2-3 公开误会
- **时长**：50min
- **触发**：M2-2 后自动
- **分任务**
  1. 论坛出现断章截图
  2. 收集完整证据（3地点）
  3. 公开澄清 or 沉默离场
- **分支**
  - 澄清：`Rep_Social +10`
  - 沉默：`Stress +10`，但保留神秘线友军

### M2-4 爱情线节点（三选一）
- **A线：青禾**（理性之爱）
  - 任务：一起完成科研与生活平衡协议
  - 关键：你能否接受“她不是你的项目”
- **B线：周砚**（危险吸引）
  - 任务：一起赢下一场资源战
  - 关键：你是否愿意为结果越线
- **C线：顾澄**（理想共振）
  - 任务：办成一次真正帮助他人的活动
  - 关键：你是否愿意牺牲个人收益

### M2-5 章末：心动并不总是答案
- **结算**：关系状态（恋人/挚友/决裂）

## M3 第三章：关系网战争（5h）

### M3-1 宿舍边界冲突
- **时长**：45min
- **分任务**
  1. 夜间噪音事件
  2. 卫生分工争议
  3. 财务AA纠纷
- **机制**：三轮谈判 mini game
- **结果**：协议成立 / 表面和解 / 彻底分裂

### M3-2 社团预算黑箱
- **时长**：65min
- **NPC**：社团财务、学生会干部
- **分任务**
  1. 拿到预算表
  2. 找到异常流水 4 条
  3. 选择内审 or 曝光
- **分支**
  - 内审：风险低，影响慢
  - 曝光：风险高，可能被反制

### M3-3 匿名账号“编辑者”
- **时长**：50min
- **分任务**
  1. 追踪 IP 线索（图书馆/机房/咖啡区）
  2. 与疑似对象对话对峙
  3. 决定公开身份与否
- **Boss**：流言编辑者（舆论战）
- **奖励**：技能`逆风发声`（公关事件容错率提高）

### M3-4 关系抉择夜
- **时长**：40min
- **内容**：三位核心角色分别提出互斥请求
- **玩家必须只选一项**
  - 帮青禾保科研名额
  - 帮周砚保社团席位
  - 帮顾澄保公益项目
- **影响**：对应两人信任大幅下降

## M4 第四章：机会猎场（6h）

### M4-1 竞赛组队
- **时长**：55min
- **分任务**
  1. 招募 3 名队员（能力互补）
  2. 分配工时与职责
  3. 处理“临时退队”事件

### M4-2 科研推荐冲突
- **时长**：70min
- **NPC**：导师、同门、行政秘书
- **分任务**
  1. 完成导师加试
  2. 发现推荐名额内定迹象
  3. 决定争取/举报/转投
- **分支与后果**
  - 争取：高压，成功则收益最高
  - 举报：道德加分，可能失去导师资源
  - 转投：短期稳定，错失高阶机会

### M4-3 实习 Offer 二选一
- **时长**：45min
- **Offer A**：高薪高压（功利路线）
- **Offer B**：低薪高成长（长期路线）
- **机制**：价值权重选择器（可视化）

### M4-4 决赛日
- **时长**：60min
- **机制**：多线程任务
  1. 上午竞赛答辩
  2. 中午导师面谈
  3. 晚上恋爱/友情危机电话
- **玩法**：同一天只能完成 2/3 事件，必须放弃一个

### M4-5 章末：成功的价格
- **对白**
  - “你赢了很多场比赛，却开始怀疑自己输掉了什么。”

## M5 第五章：第零课真相（5h）

### M5-1 档案室潜入
- **时长**：45min
- **触发**：`Mystery_ZeroClass >= 60`
- **分任务**
  1. 获取门禁权限
  2. 潜入旧档案室
  3. 找到“第零课名单”

### M5-2 名单上的名字
- **时长**：55min
- **分任务**
  1. 采访 3 位“消失者”前同学
  2. 拼接时间线
  3. 发现共同点：并非失败者，而是被系统沉默的人

### M5-3 抉择：公开还是保护
- **时长**：40min
- **分支**
  - 公开全校：引爆舆论，推进制度改革
  - 向校方闭门提交：温和改良
  - 保密仅记录：保护个体隐私

### M5-4 最终Boss：镜像林渡
- **时长**：50min
- **机制**：根据玩家历史选择动态生成 Boss 台词
- **战斗逻辑**
  1. 功利镜像：嘲讽你的理想
  2. 理想镜像：指责你的妥协
  3. 空白镜像：质问“没有观众时你是谁”

### M5-5 终章：毕业之前（2h）
- **内容**：毕业季任务串（合照、告别、最后一次夜跑）
- **多结局触发**：综合 `GPA/Stress/Trust/Ethic/Mystery` 判定

## 2. 支线任务链（详细任务化）

## S1 神秘事件：薯塔回声（8h）
- **触发**：连续 3 夜进入薯塔区域
- **分任务**
  1. S1-1 收集录音残片（5 个）
  2. S1-2 破译频谱密码
  3. S1-3 追踪“被抹去的课程编号”
  4. S1-4 对峙匿名教师 NPC
  5. S1-5 结局选择（公示/封存）
- **关键对白**
  - “你听见的不是鬼，是没人愿意听的求救。”
- **奖励**：`洞察 +2`，隐藏结局碎片

## S2 神秘事件：地下实验室（6h）
- **触发**：担任科研助理后收到匿名门禁卡
- **分任务**
  1. 找到三段门禁日志
  2. 修复老旧终端
  3. 获取实验伦理审查记录
  4. 与导师正面交涉
- **分支**
  - 揭发：`Rep_Academic ++`，风险高
  - 交易：`Money ++`，`Ethic --`
- **奖励**：装备`旧式数据镜`

## S3 食堂线：难吃的代价（7h）
- **触发**：食堂满意度<40%
- **分任务**
  1. 访谈 10 位学生生成口味热力图
  2. 潜入采购部拍下供货单
  3. 对照预算发现缩水链
  4. 帮厨艺阿姨试菜改配方
  5. 召开“听证会”决定改革路径
- **奖励**：每日恢复食物提升；`Rep_Social +15`

## S4 食堂线：最后一锅汤（4h）
- **触发**：S3 完成 + 后厨阿姨好感>=30
- **分任务**
  1. 寻找失传配方页
  2. 收集 4 种季节食材
  3. 组织“记忆食堂夜”
- **情感点**：代际和解、劳动价值被看见
- **奖励**：`Stress恢复效率 +10%`

## S5 情感线：失恋急救站（5h）
- **触发**：心理中心公告互动
- **分任务**
  1. 帮A走出自责循环
  2. 帮B停止监控前任行为
  3. 帮C完成体面告别
- **机制**：情绪识别选项（错选触发反效果）
- **奖励**：称号`情绪守门人`

## S6 情感线：月湖脱单计划（5h）
- **触发**：联谊活动失败
- **分任务**
  1. 收集双方兴趣与底线
  2. 设计首次约会场景
  3. 突发意外救场（天气/迟到/误会）
- **分支**
  - 成为情侣
  - 成为朋友（成熟结局）
- **奖励**：`社交槽位 +1`

## S7 都市传说：凌晨四点校巴（6h）
- **触发**：连续三天凌晨未休息
- **分任务**
  1. 在三站点拍到“空车影像”
  2. 与夜班保安核对线路
  3. 登上不存在的班次
  4. 在车内触发“时间账本”幻境战
- **隐喻主题**：拖延与逃避偷走人生
- **奖励**：技能`二次开机`

## S8 宿舍线：边界协议（4h）
- **触发**：宿舍冲突值>70
- **分任务**
  1. 召开第一次宿舍会议
  2. 设立规则并投票
  3. 执行一周后复盘
- **结果**
  - 成功：长期Buff`安稳睡眠`
  - 失败：室友搬离，开启新室友支线

## S9 社团线：选举与背刺（7h）
- **触发**：进入组织核心
- **分任务**
  1. 拉票与承诺清单
  2. 反黑材料事件
  3. 电视辩论战
  4. 计票夜（可触发背刺）
- **奖励**：职位权限、金币、高风险声望

## S10 打工线：深夜便利店（4h）
- **触发**：`Money < 300`
- **分任务**
  1. 收银、补货、盘点三循环
  2. 处理醉酒顾客冲突
  3. 防盗追踪小战斗
- **奖励**：`Money +`，认识情报商 NPC

## S11 家庭线：未接来电（5h）
- **触发**：主线第三章后自动
- **分任务**
  1. 回拨电话（三种语气可选）
  2. 收集父母旧照片与期望线索
  3. 选择“顺从/对抗/解释”
  4. 回家短章节（可选）
- **奖励**：`抗压上限 +10`

## S12 隐藏线：平行课表（9h）
- **触发**：S1/S2/S7 至少完成两条 + `Mystery_ZeroClass >= 80`
- **分任务**
  1. 进入平行专业世界A（商科）
  2. 进入平行专业世界B（工科）
  3. 进入平行专业世界C（人文）
  4. 三线汇合后进行“自我辩论”
- **奖励**：传奇被动`自洽`，真结局钥匙

# 《未名之海》剧情设计文档（CUHK-Shenzhen 校园探索 RPG）

> 类型：开放世界叙事 RPG / 校园探索 / 成长模拟  
> 总时长：约 100 小时（主线 30 小时 + 支线 70 小时）  
> 叙事风格：现实主义底色 + 都市传说 + 轻度幻想  
> 参考气质：赛博朋克2077（多结局伦理抉择）、GTA5（角色群像冲突）、荒野大镖客（时代与个人命运）

---

## 一、核心概念

你扮演一名刚进入港中深的大一新生 **林渡**。  
他怀揣“逆天改命”的理想来到大学，却在真实生活中被不断拉扯：

- GPA 与奖学金的压力
- 爱情与自我价值感的纠缠
- 人际关系中的权力和利益交换
- 竞赛、科研、实习机会背后的资源不平等
- 以及“做正确的事”和“做有利的事”之间的长期冲突

游戏的终极主题不是“成为最强”，而是：  
**当你拥有选择权时，你会成为什么样的人？**

---

## 二、核心系统（叙事驱动玩法）

### 1) 属性系统（可升级）
- `学术力`：影响课程表现、论文质量、科研效率
- `社交力`：影响对话分支、社团影响力、人脉资源
- `行动力`：影响探索、战斗、熬夜成本
- `洞察力`：影响线索获取、真相还原、识破谎言
- `抗压值`：过低会触发焦虑、失眠、决策失误 Debuff

### 2) 经济系统（金币）
- 来源：兼职、竞赛奖金、任务报酬、信息交易、校园跑腿
- 用途：装备升级（学习工具/探索道具）、社交活动、情绪恢复、情报购买

### 3) 战斗/冲突表现（非纯暴力）
- “怪物”可具象化为：焦虑体、流言体、虚荣体、拖延体
- 核心是策略对抗：选择“回避、对峙、求助、反击”
- Boss 战多为 **价值观战斗**（选择将影响结局）

### 4) 关系网系统
- 关键 NPC 均有好感、信任、利益绑定三条独立数值
- “高好感 != 高信任”，可能出现“关系亲密但立场对立”

---

## 三、主线剧情（30 小时）

## 序章：抵达（2h）
- 林渡报到当天在校园迷路，偶遇三位核心角色：  
  - **沈青禾**（学霸型，理性克制）  
  - **周砚**（社交达人，现实主义）  
  - **顾澄**（理想主义者，社团活跃）
- 新手任务引导：选课、宿舍磨合、第一次小组作业
- 结尾钩子：匿名论坛出现“**薯塔下的第零课**”传闻——据说每年都有学生在这里“消失于排名之外”

## 第一章：绩点风暴（5h）
- 挂科预警、奖学金竞争、排名焦虑全面爆发
- 玩家必须在“刷分课程”和“真正感兴趣课程”间取舍
- 章节 Boss：**均分幻影**（由焦虑具象化的敌人）
- 关键选择：是否帮助队友抄作业以保全团队成绩

## 第二章：心动与错位（5h）
- 感情线开启：可发展 2-3 条恋爱关系（或选择独身）
- 核心冲突：爱与被爱是否成为“学业逃避”或“价值确认”
- 事件：深夜图书馆、跨院系合作、误会与公开道歉
- 关键选择：在对方最低谷时，是“拯救”还是“尊重边界”

## 第三章：关系网战争（5h）
- 宿舍矛盾、社团内斗、学生组织资源分配不公
- 周砚提出“关系就是杠杆”，顾澄主张“原则先于结果”
- 玩家可建立自己的小圈子或成为调停者
- 章节 Boss：**流言编辑者**（操控舆论的匿名账号）

## 第四章：机会猎场（6h）
- 竞赛、科研、实习三线并行，时间管理进入极限
- 玩家发现“机会分配并不透明”：有人靠努力，有人靠信息差
- 可以选择“揭露规则漏洞”或“学习规则生存”
- 关键任务：国家级竞赛、导师推荐冲突、实习 offer 二选一

## 第五章：第零课真相（5h）
- 主角追查“薯塔下第零课”：并非神秘失踪，而是“被系统性淘汰的人”  
- 真相由多层叙事组成：心理危机、资源壁垒、沉默文化
- 最终 Boss：**镜像林渡**（你所有选择的集合体）
- 玩家需要回答：  
  - 你是否愿意牺牲别人换取上升通道？  
  - 你是否愿意承认自己的脆弱并公开求助？

## 终章：毕业之前（2h）
- 根据属性、关系、关键抉择触发结局
- 结局不以“财富/地位”单维评判，而以“完整人格”衡量

---

## 四、主线多结局设计（示例）

1. **王冠结局（高成就，低共情）**  
   你拿到顶级 offer 与高绩点，但失去重要关系，毕业演讲无人落泪。

2. **共生结局（平衡向，推荐真结局条件之一）**  
   你学会求助、合作与边界，成绩优秀，关系稳定，留下可持续的人生节奏。

3. **燃尽结局（高压崩溃）**  
   你一路冲刺却耗尽抗压值，最终休学或延期毕业。

4. **破壁结局（理想主义）**  
   你放弃短期红利，推动校园支持系统改革，影响后来者。

5. **雾海结局（隐藏）**  
   解完特定神秘支线后触发：你意识到“传奇人生”不是被看见，而是学会看见他人。

## 五、支线剧情设计（70 小时，任务化，至少 10 条）

> 任务结构格式：`任务名 / 时长 / 触发条件 / 目标 / 核心机制 / 分支结果 / 奖励`

### 1) 神秘事件线：薯塔回声（8h）
- 触发：夜间在薯塔区域连续探索 3 次
- 目标：调查“重复出现的课程名单”
- 机制：线索拼图 + 夜间潜行 + 对话审讯
- 结果：公开真相（校内震动）或私下处理（保全当事人）
- 奖励：洞察力稀有被动、隐藏结局进度

### 2) 神秘事件线：地下实验室（6h）
- 触发：加入科研助理后收到匿名门禁卡
- 目标：查明废弃实验室用途
- 机制：解密 + 环境叙事 + 伦理选择
- 结果：交给导师/媒体/封存
- 奖励：科研效率增益、特殊装备“旧式数据镜”

### 3) 食堂真相：难吃的代价（7h）
- 触发：食堂满意度连续三周下降
- 目标：揭露供货链、预算流向和管理漏洞
- 机制：跟踪采购单 + 访谈后厨 + 财务对账小游戏
- 结果：改革成功（菜品升级）或失败（黑幕反噬）
- 奖励：每日恢复道具升级、校园声望

### 4) 食堂真相：最后一锅汤（4h）
- 触发：与后厨阿姨好感达到 3 级
- 目标：找回失传菜单，举办“记忆食堂”活动
- 机制：收集食材 + 时间管理 + 群体事件
- 结果：修复代际理解，开启隐藏 NPC 故事
- 奖励：永久抗压值上限 +5

### 5) 感情支线：失恋急救站（5h）
- 触发：心理中心公告板互动
- 目标：帮助 3 位同学度过分手危机
- 机制：对话选项 + 共情判断 + 误导排除
- 结果：强行撮合会导致反效果；尊重意愿可获信任
- 奖励：社交力成长、称号“情绪守门人”

### 6) 感情支线：月湖脱单计划（5h）
- 触发：参加联谊活动失败后
- 目标：为两名 NPC 设计真实匹配方案
- 机制：兴趣图谱 + 场景布置 + 临场补救
- 结果：可成真情侣，也可能成为成熟朋友关系
- 奖励：关系网扩展槽位 +1

### 7) 校园都市传说：凌晨四点的巴士（6h）
- 触发：连续三天熬夜后自动触发
- 目标：追踪一辆不存在于时刻表的校巴
- 机制：时空错位叙事 + 选择回溯
- 结果：揭示“时间被偷走的人”隐喻（拖延与逃避）
- 奖励：行动力技能“二次开机”

### 8) 宿舍战争：边界协议（4h）
- 触发：宿舍冲突达到阈值
- 目标：制定并执行宿舍公约
- 机制：谈判、投票、执行追踪
- 结果：民主协商/权力压制/彻底决裂
- 奖励：长期 Buff“安稳休息”

### 9) 社团暗线：选举与背刺（7h）
- 触发：进入学生组织核心层
- 目标：在选举中做出政治抉择
- 机制：资源调度 + 舆论战 + 盟友管理
- 结果：赢得职位但失去朋友，或放弃权位守住原则
- 奖励：高额金币、组织权限、特殊称号

### 10) 打工线：深夜便利店（4h）
- 触发：金币低于安全线
- 目标：完成连续夜班并处理突发事件
- 机制：微经营 + 快速决策 + 防盗事件战斗
- 结果：现金充裕但体力消耗；可结识关键情报商
- 奖励：金币、稀有情报折扣

### 11) 家庭线：未接来电（5h）
- 触发：主线第三章后，父母来电事件
- 目标：处理家庭期待与个人道路冲突
- 机制：语音回忆 + 信件选择 + 回家支线
- 结果：和解/冷战/重新定义关系
- 奖励：抗压值成长、结局权重提升

### 12) 隐藏幻想线：平行课表（9h）
- 触发：完成 3 条神秘支线后解锁
- 目标：进入“如果当初选择不同专业”的平行叙事
- 机制：章节重构 + 决策镜像 + 自我对话 Boss
- 结果：解锁真结局必要碎片
- 奖励：传奇被动“自洽”

## 九、叙事深度设计原则（制作时可遵循）

1. 每个“成功”都要附带代价，不做廉价爽文。
2. 每个“反派”都给出动机，不做脸谱化恶人。
3. 爱情线必须允许“分开但成长”，不是只有“在一起”才是好结局。
4. 高分并非唯一正向反馈，心理健康与关系质量应进入结算权重。
5. 让玩家在后期回看前期选择时，产生“我当时真的那样想过”的真实共鸣。
