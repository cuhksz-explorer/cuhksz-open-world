# CUHKSZ 大世界

多人校园开放世界游戏。本仓库提供团结引擎 Windows 构建，包含运行程序、游戏场景和打包资源。

## 下载与运行

1. 从 [Windows 游戏下载](https://github.com/stefanokratzdisteln-hash/cuhksz-open-world/releases/tag/windows-build-2026-11-21) 下载全部 3 个分卷，放到同一文件夹。
2. 用 7-Zip 打开 `CUHKSZ-Open-World-Windows.zip.001`，将全部内容解压至同一目录。
3. 双击 `My project (2).exe` 启动游戏。请将同目录下的 `My project (2)_Data`、`MonoBleedingEdge` 和运行库保留在原位。

各分卷的 SHA-256 校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)。
