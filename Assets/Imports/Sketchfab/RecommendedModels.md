# Sketchfab 剧情 NPC 推荐模型（可下载）

> **说明**：Sketchfab 下载需要登录账号，并在模型页选择 **Download** → 格式选 **FBX** 或 **GLTF**，解压后放入  
> `Assets/Imports/Sketchfab/`  
> 然后在 Unity 菜单执行：**Tools → Quest System → 剧情NPC → 从 Sketchfab 导入目录配置到剧情NPC**

下载前请确认许可证为 **CC Attribution** 或 **CC0**，并保留作者署名（若要求）。

## 与本项目角色名匹配建议

将下载文件重命名（或子文件夹名）包含剧情名，便于自动匹配，例如：

- `周砚.fbx` → `Assets/NPCs/Story/周砚.prefab`
- `沈青禾.fbx` → `沈青禾.prefab`
- `林见鹿.fbx` → `林见鹿.prefab`

## 站内搜索技巧

1. 打开 https://sketchfab.com/3d-models?features=downloadable  
2. 搜索 `character`、`student`、`anime`、`male`、`female`  
3. 筛选 **Downloadable**  
4. 优先 **CC Attribution** / **CC0**，避免 NC（禁止商用）许可

## 已内置的临时方案

在未下载 Sketchfab 模型前，可先用菜单：

**Tools → Quest System → 剧情NPC → 一键应用 Supercyan 示例角色到剧情NPC**

使用项目自带的 `Supercyan Character Pack` 替换胶囊占位体。
